## 项目搭建：Day 3-5

### 2.1 技术选型决策
**推荐技术栈：**
```json
{
  "框架": "React 18 + TypeScript",
  "构建工具": "Vite",
  "样式方案": "Tailwind CSS + CSS Modules",
  "状态管理": "Zustand",
  "路由": "React Router v6",
  "动画库": "Framer Motion",
  "实时通信": "Socket.io Client",
  "HTTP客户端": "Axios",
  "代码质量": "ESLint + Prettier + Husky"
}
```

### 2.2 项目初始化
```bash
# 创建项目
npm create vite@latest voxyz-clone -- --template react-ts

# 安装核心依赖
cd voxyz-clone
npm install
npm install -D tailwindcss postcss autoprefixer
npx tailwindcss init -p

# 安装功能依赖
npm install zustand react-router-dom framer-motion socket.io-client axios
npm install -D @types/react-router-dom
```

### 2.3 项目结构设计
```
voxyz-clone/
├── src/
│   ├── components/          # 可复用组件
│   │   ├── agents/         # AI代理相关组件
│   │   ├── ui/            # 基础UI组件
│   │   ├── animations/    # 动画组件
│   │   └── layout/        # 布局组件
│   ├── pages/             # 页面组件
│   ├── stores/            # 状态管理
│   ├── services/          # API服务
│   ├── hooks/             # 自定义Hooks
│   ├── utils/             # 工具函数
│   ├── styles/            # 全局样式
│   ├── assets/            # 静态资源
│   │   ├── images/        # 图片
│   │   ├── fonts/         # 字体
│   │   └── sprites/       # 像素精灵图
│   └── types/             # TypeScript类型定义
├── public/                # 公共资源
└── config/               # 配置文件
```
